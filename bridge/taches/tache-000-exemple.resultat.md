# Résultat — Tâche 000 (exemple)

**Statut : EXEMPLE (non traité)**

Ce fichier existe uniquement pour que la tâche planifiée considère `tache-000-exemple.md`
comme déjà traité et ne l'exécute jamais. Il sert de modèle de fichier résultat.

Un vrai fichier résultat contient :
- le **statut** : FAIT ou ERREUR ;
- un **résumé** de ce qui a été fait ;
- la **liste des fichiers / liens** produits ;
- la **date/heure UTC** du traitement.
